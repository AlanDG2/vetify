**IMP-007 — 🟢 Resuelto 2026-08-07.** `IMAS-3860, Escenario 2` — no se identificaba el disparador real del modal "funcionalidad no disponible". Se completó el wizard entero vía MCP hasta la pantalla de revisión y se identificó el llamado real: `POST /api/services/assistance/493/create`, disparado únicamente al presionar "Confirmar videollamada". Bloqueándolo específicamente ahí, el modal aparece de forma limpia y reproducible (confirmado 2 veces). `TS-02 TC-01` reescrito con el flujo completo (reutilizando `VideocallFormPage`) y pasando, 0 failed.
