# Automation Project

Automation repository for Playwright UI and API tests.

## Prerequisites

- [Node.js](https://nodejs.org/) 18 or newer
- npm

## Getting started

```bash
cp .env.example .env
npm install
npx playwright install
npm test
```

Run a single website surface and its matching API suite:

```bash
npm run test:webapp
```

## Commands

| Command | Description |
| --- | --- |
| `npm test` | Run all Playwright projects |
| `npm run test:api` | Run API suites for Webapp and Institutional |
| `npm run test:webapp` | Run Webapp UI and API tests |
| `npm run test:institutional` | Run Institutional UI and API tests |
| `npm run test:ui` | Playwright UI mode |
| `npm run test:headed` | Run with visible browser |
| `npm run report` | Open HTML report from last run |

## Project layout

- `package.json` — npm scripts and dependencies
- `playwright.config.ts` — Playwright configuration
- `tsconfig.json` — TypeScript configuration
- `playwright-report/` — latest Playwright HTML report and assets
- `test-results/` — saved test-run artifacts (snapshots, traces, reports)
- `src/` — source code for API clients, pages, helpers, and types
	- `src/api/` — API client wrappers (BaseApiClient, IkeClientsApi, QuantumAuthApi, etc.)
	- `src/config/` — environment configuration
	- `src/constants/` — static constants used across tests
	- `src/helpers/` — helper utilities (e.g., `MercadoPagoCardsHelper.ts`)
	- `src/pages/` — Page Object Model classes for UI tests
		- `src/pages/institutional/` — institutional site pages and components
		- `src/pages/webapp/` — webapp pages
	- `src/types/` — shared TypeScript types
- `tests/` — Playwright test suites (UI/API)

## Notes

- The default `.env.example` values are placeholders — replace them with target Dev/QA/Prod URLs and credentials.
- Use `npm run report` to open the HTML report generated by the last run (served from `playwright-report/index.html`).

## Running tests by tag

You can mark tests with tags in the test title using either `[tag]` or `@tag` (for example: `test('[smoke] should do X', async () => { ... })` or `test('@smoke should do X', ...)`).

Set the `TAGS` environment variable with a comma-separated list of tags and run tests. Examples:

On macOS / Linux:

```bash
TAGS=smoke npm run test
TAGS=smoke,regression npm run test
```

The Playwright config will convert `TAGS` into a `grep` regexp and run only tests whose titles include any of the specified tags.

## Test user generation

> [!Note]
> Since the creation process takes aproximatelly 10min we group all the requests for new test users
> and create them first and start the tests when they are available

### Tags

**Vetify**
- `@NewVetify`: One person purchase one plan without register itself
- `@NewVetify+{X}`: One person purchase X amount of plans without register itself (e.g. `@NewVetify+3`, `@NewVetify+8`)
- `@NewVetifyUser`: New register user with one plan
- `@NewVetifyUser+{X}`: New register user with X amount of plans (e.g. `@NewVetifyUser+1`, `@NewVetifyUser+4`)
